# Storage Estimator

## Purpose
A simple Python program that estimates the total storage needed
for a number of files of a given average size.

## How to Run
1. Open a terminal in this folder.
2. Run: python storage_estimator.py
3. Enter the number of files and the average size per file in MB.

## Example
Input:
Number of files: 10
Average size per file (MB): 5

Output:
Total: 50.0 MB
